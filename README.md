# LinkedIn Dataset Search Engine
Welcome to the FullStack project! This is the official monorepo containing the backend and frontend components of our application


## 📁 Project Structure

The repository is organized into two main sub-projects for a clear separation of concerns:

- **`backend/`** - Contains the core server-side logic, APIs, and database interactions.
- **`frontend/`** - Houses the user interface, built with modern frontend technologies to deliver a seamless user experience.
